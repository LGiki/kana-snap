# KanaSnap

Interactive Japanese Kana (Hiragana & Katakana) learning PWA with charts, quizzes, and analytics.

## Commands

- `bun dev` — Start dev server on port 3000
- `bun run build` — Production build (outputs to `dist/`)
- `bun run preview` — Preview production build
- `bun run check` — Run Biome lint + format check
- `bun run lint` — Lint only
- `bun run format` — Format only
- `bun run test` — Run tests with Vitest

## Tech Stack

- **Runtime**: Bun
- **Framework**: React 19 + Vite 7
- **Routing**: TanStack Router (file-based, routes in `src/routes/`)
- **Styling**: TailwindCSS v4 with CSS custom properties for theming
- **State**: Zustand with `persist` middleware (localStorage)
- **i18n**: i18next + react-i18next (EN, JA, zh-CN, zh-TW)
- **PWA**: vite-plugin-pwa with Workbox (cache-first for static assets)
- **Icons**: lucide-react
- **Animation**: @formkit/auto-animate (shuffle transitions)
- **Audio**: Web Speech API (`speechSynthesis` with `ja-JP` lang)

## Code Style

- **Formatter**: Biome — tabs, double quotes
- **Imports**: Use `#/` alias for `src/` (e.g., `import { Kana } from "#/data/kana"`)
- **TypeScript**: Strict mode, `verbatimModuleSyntax` enabled (use `import type` for type-only imports)
- **Components**: Function components, no default exports for components (named exports only)
- **Route files**: Use `createFileRoute` / `createRootRoute` from `@tanstack/react-router`
- **Biome organize imports**: Enabled — imports are auto-sorted
- **Commit messages**: Use semantic commit messages with conventional prefixes — `feat:`, `fix:`, `chore:`, `docs:`, `refactor:`, `test:`, `style:`, `perf:`, `ci:`, `build:`

## Project Structure

```
src/
  main.tsx                  # App entry point, renders RouterProvider
  router.tsx                # TanStack Router instance
  styles.css                # Tailwind imports + theme CSS variables (light/dark)
  routeTree.gen.ts          # Auto-generated by TanStack Router plugin (do not edit)
  vite-env.d.ts             # Global type declarations for Vite define'd constants
  data/
    kana.ts                 # Kana data: gojuon, dakuten, handakuten, yoon + speakKana()
    colorSchemes.ts          # Color scheme definitions (8 built-in palettes)
  stores/
    useAppStore.ts          # Zustand store: settings, quiz history, mistake weights
  i18n/
    index.ts                # i18next init
    locales/{en,ja,zh-CN,zh-TW}.ts  # Translation files
  components/
    AppIcon.tsx              # SVG app icon component with gradient
    ConfirmDialog.tsx        # Reusable confirmation dialog (used for destructive actions)
    Navigation.tsx           # Top nav (desktop) + bottom nav (mobile)
    KanaCard.tsx             # Single kana card display
    KanaChart.tsx            # Full chart with display modes, shuffle, detail modal
    KanaDetailModal.tsx      # Modal with hiragana/katakana/romaji + audio playback
    KanaFeed.tsx             # Infinite scroll kana feed with pop quizzes and streak milestones
    Quiz.tsx                 # Quiz engine: weighted selection, keyboard shortcuts (1-4), analytics
    QuizResult.tsx           # Score display + incorrect answer review
    Heatmap.tsx              # GitHub-style SVG contribution heatmap
    LineChart.tsx            # SVG line chart for quiz activity
    StreakCounter.tsx         # Current/longest streak + total quizzes + average score
    Tabs.tsx                 # Reusable tab switcher component
  routes/
    __root.tsx               # Root layout: theme sync, language sync, nav
    index.tsx                # / — Kana Chart page
    quiz.tsx                 # /quiz — Quiz page (includes analytics tab)
    feed.tsx                 # /feed — Infinite scroll kana feed with embedded quizzes
    settings.tsx             # /settings — Theme, color scheme, language, data import/export/reset, version info
```

## Key Patterns

- **Theming**: `data-theme="dark"` attribute on `<html>`, CSS variables in `styles.css`, Tailwind `dark:` variant via `@custom-variant`. Color schemes (8 palettes) swap `--color-primary-*` CSS variables
- **State persistence**: Zustand `persist` middleware saves to `localStorage` under key `kana-snap-storage`
- **Quiz weighting**: `weight = 1 + mistakeCount` — kana answered incorrectly appear more frequently
- **Route tree**: Auto-generated by `@tanstack/router-plugin`. Adding/removing files in `src/routes/` regenerates `routeTree.gen.ts` on dev server start or build
- **Build-time constants**: `__APP_VERSION__`, `__COMMIT_HASH__`, `__COMMIT_DATE__` injected via Vite `define` in `vite.config.ts`, typed in `src/vite-env.d.ts`
- **PWA**: Service worker auto-updates, precaches all static assets. Manifest configured in `vite.config.ts`
