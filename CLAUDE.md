# KanaSnap

Interactive Japanese Kana (Hiragana & Katakana) learning PWA with charts, quizzes, handwriting recognition, stroke order animations, and analytics.

## Commands

- `bun dev` — Start dev server on port 3000
- `bun run build` — Production build (outputs to `dist/`)
- `bun run preview` — Preview production build
- `bun run check` — Run Biome lint + format check
- `bun run lint` — Lint only
- `bun run format` — Format only
- `bun run test` — Run tests with Vitest

## Tech Stack

- **Runtime**: Bun
- **Framework**: React 19 + Vite 8
- **Routing**: TanStack Router (file-based, routes in `src/routes/`)
- **Styling**: TailwindCSS v4 with CSS custom properties for theming
- **State**: Zustand with `persist` middleware (localStorage)
- **i18n**: i18next + react-i18next (EN, JA, zh-CN, zh-TW)
- **PWA**: vite-plugin-pwa with Workbox (cache-first for static assets)
- **Icons**: lucide-react, @icons-pack/react-simple-icons
- **Animation**: @formkit/auto-animate (shuffle transitions), react-confetti
- **Audio**: Web Speech API (`speechSynthesis` with `ja-JP` lang)
- **Charts**: chart.js + react-chartjs-2
- **Handwriting Recognition**: onnxruntime-web (ONNX Runtime for in-browser ML inference)
- **Utilities**: tailwind-merge, clsx

## Code Style

- **Formatter**: Biome — tabs, double quotes
- **Imports**: Use `#/` alias for `src/` (e.g., `import { Kana } from "#/data/kana"`)
- **TypeScript**: Strict mode, `verbatimModuleSyntax` enabled (use `import type` for type-only imports)
- **Components**: Function components, no default exports for components (named exports only)
- **Route files**: Use `createFileRoute` / `createRootRoute` from `@tanstack/react-router`
- **Biome organize imports**: Enabled — imports are auto-sorted
- **Commit messages**: Use semantic commit messages with conventional prefixes — `feat:`, `fix:`, `chore:`, `docs:`, `refactor:`, `test:`, `style:`, `perf:`, `ci:`, `build:`

## Key Patterns

- **Theming**: `data-theme="dark"` attribute on `<html>`, CSS variables in `styles.css`, Tailwind `dark:` variant via `@custom-variant`. Color schemes (8 palettes) swap `--color-primary-*` CSS variables. Anti-FOUC inline script in `vite.config.ts` applies persisted theme before first paint
- **State persistence**: Zustand `persist` middleware saves to `localStorage` under key `kana-snap-storage` (defined in `src/constants.ts`)
- **Quiz modes**: Multiple choice (hiragana/katakana recognition) and handwriting (draw kana, recognized via ONNX model). Quiz engine in `src/lib/quizEngine.ts`
- **Quiz weighting**: `weight = 1 + mistakeCount` — kana answered incorrectly appear more frequently
- **Handwriting recognition**: Unified ONNX model in `src/lib/kanaModel.ts` recognizes both hiragana and katakana drawn on `DrawingCanvas`
- **Stroke animations**: SVG stroke-by-stroke animations via `src/lib/strokeAnimator.ts`, displayed in `StrokeSvg.tsx`. SVG files derived from Klee One font
- **Route tree**: Auto-generated by `@tanstack/router-plugin`. Adding/removing files in `src/routes/` regenerates `routeTree.gen.ts` on dev server start or build
- **Build-time constants**: `__APP_VERSION__`, `__COMMIT_HASH__`, `__COMMIT_DATE__` injected via Vite `define` in `vite.config.ts`, typed in `src/vite-env.d.ts`
- **PWA**: Service worker with prompt-based update flow (`UpdatePrompt.tsx`), precaches all static assets. Manifest configured in `vite.config.ts`
- **Build optimizations**: HTML minification (html-minifier-terser), SVG minification (svgo with stroke SVG ID preservation), Terser for JS, legacy browser support (@vitejs/plugin-legacy)
